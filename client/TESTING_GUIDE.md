# Ръководство за тестване на достъп от други устройства

## Бърз тест

### От сървъра (компютъра, където работи системата):

```bash
cd /home/anton/supermarket-pos/client
./test-network-access.sh
```

Това ще:
1. Тества локалния достъп
2. Тества достъпа по мрежовия IP
3. Мониторира заявки от други устройства (60 секунди)
4. Показва последните заявки

### От смартфона/лаптопа:

1. **Уверете се, че сте в същата Wi-Fi мрежа:**
   - IP адресът трябва да започва с `192.168.80.`
   - Проверете Wi-Fi настройките на устройството

2. **Отворете браузър и отидете на:**
   ```
   http://192.168.80.120:3001
   ```

3. **Опитайте да се логнете:**
   - Email: `admin@abv.bg`
   - Password: `123456`

4. **Проверете конзолата на браузъра (F12):**
   - Натиснете F12 (или дълго натискане на мобилен)
   - Отидете в "Console" таб
   - Вижте за грешки

## Какво да търсите

### ✅ Успешен тест:
- Страницата се зарежда
- Виждате login формата
- Можете да се логнете
- В конзолата няма грешки

### ❌ Проблеми и решения:

#### 1. "This site can't be reached" / "Connection refused"
**Причина:** Заявките не достигат до сървъра
**Решение:** 
- Проверете AP Isolation на рутера
- Проверете firewall: `sudo ufw status`

#### 2. CORS errors в конзолата
**Причина:** Backend не разрешава origin-а
**Решение:** Проверете CORS конфигурацията в backend

#### 3. "Network Error" или "ERR_CONNECTION_REFUSED"
**Причина:** Мрежова изолация
**Решение:** Изключете AP Isolation на рутера

#### 4. Бял екран след login
**Причина:** Frontend не получава данни от backend
**Решение:** Проверете логовете: `docker logs pos-shop-frontend`

## Диагностика

### Проверка на заявките в реално време:

```bash
# От сървъра, докато тествате от смартфон/лаптоп:
docker logs -f pos-shop-frontend
```

Ако виждате заявки от IP адреси различни от `192.168.80.120`, това означава, че заявките достигат!

### Проверка на CORS:

```bash
# Тест на CORS от различни origins
curl -v -H "Origin: http://192.168.80.101:3001" \
  http://localhost:8087/api/v1.0/health
```

Трябва да видите `Access-Control-Allow-Origin` header в отговора.

### Проверка на портовете:

```bash
# Проверете дали портовете слушат на всички интерфейси
ss -tlnp | grep -E ":3001|:8087"
```

Трябва да видите `0.0.0.0:3001` и `0.0.0.0:8087`.

## Често срещани проблеми

### Проблем: Не виждам заявки от други устройства в логовете
**Решение:** AP Isolation е включен на рутера → изключете го

### Проблем: Виждам заявки, но получавам CORS грешки
**Решение:** Backend CORS конфигурация → вече е поправена, но проверете отново

### Проблем: Страницата се зарежда, но не мога да се логна
**Решение:** Проверете credentials и backend логове
